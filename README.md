# Trener

Aplikacja (PWA) do prowadzenia podopiecznych i ich planów treningowych.

## Źródła bazy ćwiczeń
- Ilustracje i dane ćwiczeń: Exercise data by [RepDB](https://repdb.co) — pobierane bezpośrednio z exercise-dataset.com, polskie nazwy to tłumaczenie własne.
- Zdjęcia ćwiczeń: [free-exercise-db](https://github.com/yuhonas/free-exercise-db) (Unlicense / domena publiczna).
